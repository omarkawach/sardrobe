# Sardrobe components

This package contains the small set of shared React components used by Sardrobe.
It builds on [Base UI](https://base-ui.com/) and the product's design tokens.

Use the stories in the sidebar to inspect supported states, themes, and accessibility
behavior. Components belong here only when Sardrobe uses them in multiple places or
when they provide an important shared accessibility primitive.

Theme previews use the same `data-theme` attribute and `sardrobe-light` or
`sardrobe-dark` classes as the application. Tokens live in
`src/styles/tokens.css`; shared component styles are exported through
`src/styles/index.css`.

For product setup and contribution rules, see the repository README and
CONTRIBUTING guide.
