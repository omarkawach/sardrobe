# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's **Security → Report a vulnerability** flow to create a private GitHub security advisory.

Include the affected route or component, reproduction steps, likely impact, and any suggested mitigation. Do not include real user wardrobe data, session cookies, OAuth credentials, or model-bucket credentials.

## Supported version

Security fixes target the latest code on the default branch. Older forks and deployments should update before requesting support.
